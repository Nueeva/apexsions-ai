Apexsions Agentic Runtime

Apexsions AI is a distributed runtime for spawning and orchestrating autonomous characters and dynamic world state in digital universes, gaming servers, and simulation engines. Powered by the Anthropic Claude 5.5 Model Family (Claude Sonnet 5.5, Haiku 5.5, and Opus 5.5) with 1 Million token persistent memory and Adaptive Thinking.

ℹ
Inference Pipeline: Incoming game perception events are converted to high-dimensional spatial contexts, augmented with 1M-token episodic vector memory, and dispatched through Anthropic's Claude 5.5 streaming API with adaptive thinking and strict tool validation.

Quickstart Installation

1. Install Package

npm install @apexsions/ai-runtime # or pip install apexsions-runtime

2. Environment Configuration

Export your API authentication credentials:

export APEXSIONS_API_KEY="apx_live_sec_99a81bc2"
export APEXSIONS_WORLD_ID="realm_aetherion_prime"

3. Initialize & Stream

import { ApexsionsRuntime } from '@apexsions/ai-runtime';

const runtime = new ApexsionsRuntime();
const agent = runtime.registerEntity({
  id: 'npc_gatekeeper',
  model: 'claude-sonnet-5-5-20260928',
  adaptiveThinking: { effort: 'high', budgetTokens: 8192 },
  contextWindow: 1_000_000
});

const stream = await agent.perceiveAndAct({
  event: 'PLAYER_GREETING',
  player: { username: 'Aria', rank: 'Sovereign' }
});

for await (const token of stream) {
  process.stdout.write(token);
}

REST API Reference

POST /v1/agents/{agent_id}/perceive

Ingests world sensory data and initiates streaming agentic reasoning loop.

Headers:
Authorization: Bearer <YOUR_API_KEY>
Content-Type: application/json

Response: text/event-stream (SSE)
